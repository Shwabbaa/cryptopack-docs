Development
==============

Regular Items
----------
#. Install and open BlockBench
#. Select "New Java Block/Item"
#. Create and texture your item, and set up the appearance in the Display tab.
#. Submit the item

Bows / Crossbows 
----------

* Bows and crossbows have 4 animation frames for loading the weapon

* Crossbows are actually held differently, so you will need to account for that when modelling in Blockbench (select bow in display tab)

These are how the frames are organised:

* 1 frame of unloaded item

* 2 frames drawing back / loading

* 1 frame fully charged

Submit all 4 models. You may also submit more or fewer "drawing back" models.

Hats
----------
The process of creating a hat is the same as creating a regular item like above, but make sure for the display tab you have set up and aligned the item correctly to fit the player's head.

Armour Set
----------
Armour sets are applied directly above skin layers and cannot have a model, only re-textured. One armour set requires two textures (one for helmet, chestplate and boots, one for leggings)
Create two models using the "Minecraft Skin" option and selecting "Armor (Main)" and "Armor (Leggings)".
You should also submit 4 16x16 textures for the armour items shown in the inventory.

Furniture Sets / Blocks
----------
The process of creating a custom block is the same as creating a regular item like above, but make sure for the display tab you set up the Item Frame display properly for an invisible item frame. On CryptoCraft, you can make item frames invisible and indestructable using a wooden hoe.
